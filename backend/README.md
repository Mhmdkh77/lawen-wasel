# Lawen Wasel backend

This directory contains the Laravel API and admin panel. For setup, demo credentials, optional map and routing keys, and API documentation, see the [project README](../README.md).

The repository includes a populated `database/database.sqlite`. You can use it immediately after installing dependencies and creating `.env`; do not run the full seeder against it. For a disposable rebuild, the root README explains how to recreate and seed the database.
